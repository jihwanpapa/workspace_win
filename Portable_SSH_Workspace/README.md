# 휴대용 SSH 접속 패키지 사용 설명서 🚀

이 패키지는 외부 윈도우 노트북이나 Mac 환경에서 번거로운 터미널 프로그램(WSL, oathtool, expect 등)을 새로 설치할 필요 없이, **오직 내장된 기능만을 활용해 SSH 터널링과 OTP 자동 로그인을 수행**할 수 있도록 만들어졌습니다.

---

## 🔒 1단계: 내 접속 정보 설정하기 (최초 1회 필수)

패키지를 사용하기 위해서는 먼저 본인의 비밀번호와 구글 OTP 시크릿 키를 입력해 주어야 합니다.

1. 압축을 푼 폴더 안에 있는 **`config.txt`** 파일을 메모장(또는 텍스트 편집기)으로 엽니다.
2. 아래 세 가지 정보를 본인의 정보로 채워 넣고 저장합니다.

```text
SSH_USER=jinyoung.hur         <-- 본인의 접속 계정명
SSH_PASS=내비밀번호입력       <-- SSH 접속에 사용하는 비밀번호
OTP_SECRET=내시크릿키입력     <-- (중요) Google OTP 발급 시 사용한 영문/숫자 혼합 문자열
```

> **💡 OTP 시크릿 키를 모른다면?**
> 현재 사용 중이신 업무용 노트북의 WSL 터미널을 열고, 아래 명령어를 입력하시면 현재 설정된 시크릿 키를 확인하실 수 있습니다.
> `echo $OTP_global_ipa` 
> (만약 빈칸으로 나온다면, `~/.zshrc` 파일이나 구글 OTP 앱을 처음 등록할 때 보관해 둔 문자열을 찾아 붙여넣어 주세요.)

---

## 💻 2단계: Windows 노트북에서 사용하기

Windows에 내장된 PowerShell 기능을 사용하므로 별도의 프로그램 설치가 **전혀 필요 없습니다.**

1. `Windows` 폴더 안의 **`tunnel_launcher.bat`** 파일을 더블 클릭하여 실행합니다.
   * 검은색 창이 열리면서 터널이 연결됩니다. (접속하는 동안 이 창을 닫지 마세요)
2. `Windows` 폴더 안의 **`sshw_launcher.bat`** 파일을 더블 클릭하여 실행합니다.
   * 접속할 서버 이름(예: `prd-us`)을 입력하고 엔터를 누릅니다.
   * **(주의)** 이 직후 약 2초간 팝업된 SSH 창에 비밀번호와 OTP가 **자동으로 타이핑**되므로, 잠시만 키보드와 마우스를 건드리지 말고 기다려 주세요!
   * 자동으로 접속이 완료됩니다!

---

## 🍎 3단계: Mac (맥북 등) 환경에서 사용하기

Mac에 기본 내장된 Python과 expect 기능을 활용하여 작동합니다. 최초 1회만 보안 실행 권한을 주어야 합니다.

**최초 1회 권한 설정:**
1. Mac의 **터미널(Terminal)** 앱을 엽니다.
2. `bash ` (마지막 띄어쓰기 필수)를 타이핑하고, 폴더 내의 **`Mac/0_설정.command`** 파일을 터미널 창으로 끌어다 놓은 뒤 엔터를 칩니다.

**평소 접속할 때:**
1. **`Mac/1_connect_tunnel.command`** 파일을 더블클릭합니다.
   * 터미널 창이 열리며 터널이 연결됩니다. (닫지 마세요)
2. **`Mac/2_sshw.command`** 파일을 더블클릭합니다.
   * 터미널 창이 열리면 접속할 서버 이름(예: `prd-us`)을 입력합니다.
   * 비밀번호와 OTP가 백그라운드에서 완벽하게 자동 계산되어 즉시 접속됩니다!
