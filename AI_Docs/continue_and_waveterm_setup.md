# 완벽한 100% 무료 로컬 AI 환경 구축 가이드

Cursor의 상술에서 벗어나, 로그인이나 과금 유도 없이 사용자님의 PC 자원(GPU)과 Ollama만을 활용하는 최강의 조합 설정 방법입니다.

---

## 1. VS Code + Continue 확장 프로그램 설정

Continue는 코드를 작성하거나 에러를 분석할 때 사용하는 최고의 오픈소스 AI 보조 도구입니다.

### ⚙️ 설정 방법
1. VS Code 좌측 메뉴에서 돋보기 밑밑에 있는 **Continue 아이콘(로봇 또는 겹친 화살표 모양)**을 클릭합니다.
2. 패널 하단(또는 상단)에 있는 **`+` (Add Model)** 버튼이나 **톱니바퀴(⚙️ 설정)** 아이콘을 클릭합니다.
3. Provider(제공자) 목록에서 **`Ollama`**를 선택합니다.
4. Model Name(모델명)에 **`qwen2.5-coder:7b`** (또는 현재 주력으로 쓰시는 모델명)를 정확히 입력합니다.
5. Base URL은 자동으로 `http://127.0.0.1:11434` 로 잡힙니다. (그대로 두시면 됩니다.)
6. 완료(Add)를 누르면 끝입니다!

### 🚀 사용 꿀팁
- 터미널에서 에러가 났을 때: 에러 텍스트를 마우스로 드래그(블록 지정)한 뒤 **`Ctrl` + `L`** 을 누르면, 해당 에러가 우측 Continue 채팅창으로 쏙 들어갑니다. 바로 "이거 어떻게 고쳐?" 라고 물어보세요!
- 코드 분석: `agent.py` 코드를 띄워두고 **`Ctrl` + `I`** 를 누르면 코드 한가운데에 입력창이 뜹니다. "이 부분에 여러 줄 입력 기능 추가해 줘"라고 치면 바로 코드를 수정해 줍니다.

---

## 2. Wave Terminal 로컬 AI 설정

Wave Terminal은 파워쉘(PowerShell)이나 WSL 터미널을 대체할 수 있는, AI 연동이 기본 탑재된 차세대 오픈소스 터미널입니다.

### ⚙️ 설정 방법
1. Wave Terminal을 실행합니다.
2. 터미널 우측 상단을 보시면 **AI 챗(Chat) 패널**을 여는 버튼(또는 마스크/로봇 아이콘)이 있습니다. 이를 클릭하여 채팅창을 엽니다.
3. 채팅창 상단 또는 하단에 있는 **모델 선택 드롭다운(기본값: gpt-3.5 등)**을 클릭합니다.
4. **`Manage Models`** (또는 Add Model) 메뉴로 들어갑니다.
5. Provider를 **`Ollama`**로 선택하고, URL은 `http://127.0.0.1:11434` 로 맞춥니다.
6. 모델명에 **`qwen2.5-coder:7b`** 를 입력하고 저장합니다.

### 🚀 사용 꿀팁
- 터미널 창(블록 단위로 쪼개진 화면)에서 쳤던 명령어와 에러 결과값이 화면에 남아있을 때, 우측 AI 창에 대고 "방금 에러 왜 뜬 거야?" 라고만 물어봐도 **AI가 현재 터미널 화면을 스스로 읽고** 답변을 줍니다! (복사/붙여넣기가 필요 없습니다.)
