# Cursor IDE 로컬 AI (Ollama) 연동 가이드

Cursor IDE는 기본적으로 유료 클라우드 모델(GPT-4, Claude 등)을 바라보고 있지만, 설정을 약간만 바꿔주면 사용자님의 PC에서 돌고 있는 **무료 로컬 Ollama 모델**을 메인 두뇌로 사용할 수 있습니다.

## ⚙️ 1단계: Cursor에 Ollama 주소 연결하기

1. **Cursor 실행 및 설정 열기**
   - Cursor를 실행하고 단축키 `Ctrl` + `,` 를 누르거나 우측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 **Settings(설정)** 창을 엽니다.
2. **Models 메뉴 이동**
   - 설정 창 좌측 메뉴에서 **Models**를 클릭합니다.
3. **OpenAI Base URL 덮어쓰기**
   - 스크롤을 내려 **OpenAI API Key** 섹션을 찾습니다.
   - API Key 입력란에 아무 글자나 대충 입력합니다 (예: `ollama`). *Ollama는 무료라 인증키가 필요 없지만 빈칸이면 Cursor가 에러를 냅니다.*
   - 바로 아래에 있는 **Override OpenAI Base URL** 스위치를 켭니다.
   - 주소 입력란에 `http://127.0.0.1:11434/v1` 을 정확히 입력합니다.

## 🧠 2단계: 로컬 모델 이름 추가하기

1. **모델 리스트에 내 모델 추가**
   - 같은 화면 맨 위로 스크롤을 올리면 현재 활성화된 모델 이름들(claude-3.5-sonnet 등)이 보입니다.
   - 그 아래에 있는 **`+ Add model`** (모델 추가) 버튼을 누릅니다.
   - 모델 이름에 사용자님이 현재 Ollama에서 쓰고 있는 주력 코딩 모델 이름인 **`qwen2.5-coder:7b`** (또는 설치하신 모델명)을 정확히 타이핑하고 엔터를 칩니다.
2. **기본 모델로 설정**
   - 방금 추가한 `qwen2.5-coder:7b` 옆의 스위치를 켜줍니다.
   - 기존에 있던 다른 유료 모델들(gpt-4o, claude 등)의 스위치는 모두 꺼줍니다(Off). (선택사항이지만 이렇게 해야 항상 무료 로컬 모델만 씁니다.)

## 🚀 3단계: 터미널 에러 실시간 분석 써보기 (완성!)

1. **내 프로젝트 열기**
   - 상단 메뉴 `File > Open Folder`를 눌러서 사용자님의 주 작업 폴더(`C:\Users\hjy_p\DEV` 등)를 엽니다.
2. **터미널 열기**
   - 단축키 `Ctrl` + `` ` `` (백틱, 숫자 1 왼쪽 키)를 누르면 화면 하단에 터미널 창이 올라옵니다.
   - 여기서 `wsl`을 치면 평소 쓰시던 리눅스 환경과 똑같이 접속됩니다.
3. **AI에게 터미널 화면 통째로 물어보기**
   - 우측 패널의 AI 채팅창(Chat)을 엽니다.
   - 채팅 입력창에 **`@terminal`** 이라고 치고 엔터를 누릅니다.
   - *"지금 터미널에 나온 에러가 뭐야? 어떻게 고쳐?"* 라고 한글로 물어보세요!
   - AI가 로컬 GPU를 윙~ 돌리면서 터미널 화면을 읽고 즉시 해결책을 알려줄 것입니다.

## ⚠️ 주의사항: 모델이 잠겨있거나 안 보일 때
- Cursor에는 두 가지 채팅창이 있습니다. Ctrl + I를 누르면 나오는 **Composer** 창은 유료 기능이 일부 섞여 있어서 모델 변경이 잠겨있을 수 있습니다.
- 반드시 **Ctrl + L**을 눌러서 우측에 열리는 **일반 Chat(채팅) 패널**을 사용하세요.
- 채팅창 하단에 적힌 모델명(예: cursor-fast)을 클릭하면 아까 추가한 qwen2.5-coder:7b를 선택할 수 있습니다.
